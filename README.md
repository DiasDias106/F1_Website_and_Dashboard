# 🏎️ **F1 Website and Dashboard — ASP.NET Themed Application**

**F1 Website and Dashboard** is a comprehensive Formula 1–themed web platform built using **ASP.NET**, **JavaScript**, **Chart.js**, **JSON**, and **SQL Server**.  
The system is divided into two main sections — a **public website** showcasing F1 content and mini-games, and an **interactive admin dashboard** for managing data and simulating the operations of an F1 team leader.

---

## 🌐 **Main Features**

### 🏁 **Public Website**
- 📄 **Informative Pages:** Explore detailed sections about the F1 universe, teams, and racing events.  
- 🚗 **Team Pages:** Each team has a dedicated page featuring a **3D car model** *(models not created by me)*.  
- 🎮 **Mini-Games Section:** Includes a variety of interactive tools and games such as:  
  - 💱 Currency converter using an API  
  - 🖼️ Image converter  
  - 🔐 Text encryptor  
  - 🔊 Text-to-speech converter  
  - …and many more!  
- 📬 **Email Integration:** Supports both **newsletter subscription** and **custom email sending**.  
- 🌲 **F1-Themed TreeView:** Hierarchical navigation system for quick access to resources.  

---

### 📊 **Admin Dashboard**
- 🧑‍💼 **Custom Login (Paddock Club):**  
  Full account system with role creation, role management, profile editing, and account deletion.  
- 🏎️ **Team & Driver Management:**  
  Manage, edit, and export team and driver data to **PDF** or **Excel**.  
- 📅 **Calendar and Track Management:**  
  Filterable event and track listings with **export options** to PDF and Excel.  
- 📈 **Interactive Dashboard:**  
  Custom **Chart.js** graphs and data visualizations.  
- 🧩 **LINQ-Based Management App:**  
  Manage teams, pilots, and statistics using LINQ for efficient data operations.  
- 🛒 **Interactive Store:**  
  Fully functional **F1-themed webstore** with cart and admin management tools.  
- 📬 **Newsletter and Email System:**  
  Send personalized or mass emails directly from the dashboard.  

---

## ⚙️ **Technologies Used**

- 💬 **ASP.NET (C#)** – main application logic and MVC architecture  
- 🗃️ **SQL Server** – relational database management  
- 📊 **Chart.js** – data visualization and dashboard charts  
- ⚙️ **LINQ** – efficient data querying and manipulation  
- 🧠 **JavaScript / JSON** – interactivity and data exchange  
- 💅 **Bootstrap / CSS** – modern responsive UI styling
